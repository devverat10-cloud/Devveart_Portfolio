A 3-step mobile user journey engineered to eliminate drop-off, build reassurance for anxious life guidance seekers (marriage, career), and incentivize first-session consultations through contextualized virtual currency.

◉ Human-Centered Methodology

My Design Thinking Process

How I turn messy, ambiguous challenges into clean user experiences and production-ready code:

01

Discover

User interviews, competitor benchmarking, and uncovering real user friction points.

02

Define

Mapping user journeys, sitemaps, task models, and information architecture.

03

Wireframe

Rapid low-fi sketches and layout testing before getting distracted by colors.

04

Figma UI

Design system tokens, atomic components, micro-interactions, and accessibility.

05

Code & Test

Responsive front-end development with 100% design fidelity and clean code.
